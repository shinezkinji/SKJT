SEC//01 — DEFINISI

Apa itu Sistem Keamanan Jaringan?

Kumpulan kebijakan, teknologi, dan proses untuk melindungi jaringan komputer & data dari akses tidak sah, serangan siber, dan gangguan layanan.

Tujuan Utama

  • Confidentiality — data tidak bocor ke pihak tak berwenang
  • Integrity — data tidak diubah/dirusak
  • Availability — layanan selalu tersedia

Ancaman Umum

  • Malware — virus, worm, trojan, ransomware
  • DDoS — membanjiri server hingga lumpuh
  • Phishing — pencurian kredensial lewat penipuan
  • Man-in-the-Middle — penyadapan komunikasi
Klik perisai — ancaman (merah) terpental dari server

SEC//02 — PRINSIP DASAR

CIA Triad — 3 Pilar Keamanan

C — CONFIDENTIALITY

Kerahasiaan: data hanya diakses pihak berwenang. Penerapan: enkripsi, password, 2FA.

I — INTEGRITY

Integritas: data tidak diubah ilegal. Penerapan: hash, checksum, digital signature.

A — AVAILABILITY

Ketersediaan: sistem selalu siap dipakai. Penerapan: backup, redundancy, anti-DDoS.

Klik bola C / I / A pada piramida untuk detail tiap pilar

SEC//03 — ARSITEKTUR

Struktur: Defense in Depth

Pertahanan disusun berlapis — jika satu lapis tembus, masih ada lapis berikutnya. Data kritis berada di inti terdalam:

  • Fisik — CCTV, kunci ruang server, access card
  • Jaringan — firewall, segmentasi, IDS/IPS
  • Endpoint — antivirus, patch OS
  • Aplikasi — validasi input, secure coding
  • Data — enkripsi, backup, klasifikasi
Klik tiap lapisan bola untuk memperbesar & melihat namanya

⚠ SIMULASI SERANGAN
ATK//01 — DDOS ATTACK

DDoS — Banjir Trafik Palsu

Distributed Denial of Service: penyerang mengendalikan ribuan komputer (botnet) untuk mengirim permintaan palsu serentak, membuat server kelebihan beban dan lumpuh — pengguna asli tidak bisa mengakses layanan.

Jenis Serangan

  • Volumetric — membanjiri bandwidth (UDP flood)
  • Protocol — SYN flood, menghabiskan koneksi
  • Application layer — HTTP flood meniru user asli

Pertahanan

  • Rate limiting & filter trafik anomali
  • CDN / scrubbing center anti-DDoS
  • Load balancing & redundansi server
Klik server — intensitas serangan naik, server kewalahan

SEC//04 — PERIMETER

Firewall — Tembok Penyaring

Gerbang pemeriksaan antara jaringan internal & internet. Menyaring paket berdasarkan rule: mengizinkan yang aman, memblokir yang mencurigakan.

Metode

  • Packet filtering — cek IP & port tiap paket
  • Stateful inspection — lacak status koneksi
  • Proxy — perantara permintaan
Klik balok firewall untuk membuka/menutup celah — amati ancaman lolos atau tidak

ATK//02 — MALWARE INTRUSION

Malware — Infeksi dari Dalam

Worm & virus menyusup ke jaringan lalu menginfeksi node satu per satu — menyebar otomatis tanpa aksi pengguna. Node biru yang tersentuh worm berubah merah = terinfeksi.

Jenis Berbahaya

  • Worm — menyebar sendiri lewat jaringan
  • Trojan — menyamar sebagai software sah
  • Ransomware — mengenkripsi data, minta tebusan
  • Spyware — mencuri data diam-diam

Pertahanan

  • Antivirus/EDR + update signature rutin
  • Patch sistem & aplikasi segera
  • Segmentasi jaringan + least privilege
Klik — lepaskan gelombang infeksi, klik lagi untuk membersihkan

SEC//05 — DETEKSI & RESPONS

IDS / IPS & Anti-Malware

IDS memantau trafik & mendeteksi aktivitas mencurigakan. IPS melangkah lebih jauh: otomatis memblokir ancaman.

Metode Deteksi

  • Signature-based — cocokkan pola serangan dikenal
  • Anomaly-based — deteksi perilaku tak wajar
Klik — picu gelombang SCAN yang menghancurkan semua virus

ATK//03 — MAN IN THE MIDDLE

MitM & Phishing — Penyadapan

Man-in-the-Middle: penyerang menyusup di antara dua pihak yang berkomunikasi, menyadap bahkan memalsukan data tanpa disadari korban. Biasanya diawali phishing — email/halaman login palsu untuk mencuri kredensial.

Modus Umum

  • WiFi rogue AP — hotspot palsu di tempat umum
  • ARP spoofing — memalsukan identitas di LAN
  • Session hijacking — membajak sesi login

Pertahanan

  • HTTPS/SSL-TLS di semua komunikasi
  • VPN untuk jaringan publik
  • Edukasi anti-phishing + verifikasi 2 langkah
Klik penyerang merah — ia menyadap & menggandakan paket data

SEC//06 — KONEKSI AMAN

VPN — Tunnel Terenkripsi

Membuat "terowongan" terenkripsi di atas jaringan publik. Data di dalamnya tidak bisa disadap — solusi langsung untuk melawan MitM di scene sebelumnya.

Protokol

  • IPSec — enkripsi level paket IP
  • OpenVPN / WireGuard — cepat & fleksibel
  • SSL/TLS VPN — berbasis browser
Klik tunnel — aktifkan BOOST, penyadap di luar tetap buta
